The holdout decides the number

measured, not estimated

Holding out whole documents leaves the model free to recognise a page design it trained on. Holding out a whole design does not, and it is the split that predicts a vendor template nobody has seen. The same model, the same corpus, two splits:

splitaccuracyfloorcoverage
held out by source document0.9580.7582.6%
held out by page design0.7920.8547.2%

The manifest carried 0.90. On the honest split 0.85 answers more documents with the same zero errors, so five points of coverage were being given away for nothing.

By degradation

one floor over all four costs the clean ones

The floors diverge. A single global floor is set by the worst profile and charges every other profile for it, which is the argument for routing on the degradation the normalizer already reports.
